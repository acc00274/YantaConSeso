# YantaConSeso
Proyecto FIS

Esta aplicación de comidas está diseñada para ofrecer una experiencia cómoda y sencilla al usuario. Con características como planes de comida personalizables, edición de recetas, y una base de datos para almacenar recetas, la aplicación también permite categorizar alergias, asegurando un uso seguro y eficiente.
